Product Requirements Document

Why Project Purpose

This project helps users discover exhibitions and cultural spaces in Seoul based on mood, atmosphere, and budget — rather than simply choosing popular places. Since many people struggle to decide where to go for exhibitions or dates, this platform provides personalized recommendations through data visualization.

Who Target Audience

  • People in their 20s
  • Exhibition enthusiasts
  • Couples searching for date courses
  • Users interested in aesthetic and cultural spaces in Seoul

What Key Features

  • Mood-Based Recommendation System (Healing, Aesthetic, Quiet, Artistic, Traditional)
  • Neighborhood Comparison Tool (Seongsu, Bukchon, Itaewon, Hannam…)
  • Budget-Based Recommendation
  • Interactive Data Visualization (bar, radar, map)

How Technical Stack

Python 3.9+ Streamlit Pandas Plotly GitHub Streamlit Cloud

Built using Python and the Streamlit library, utilizing curated datasets related to exhibition locations, cultural venues, visitor preferences, and budget information.

3-Step Build Plan
1

Basic UI Layout & Sample Dataset Setup

Create the GitHub repository and Streamlit environment. Prepare a simple dataset of exhibitions and cultural spaces in Seoul. Design a homepage and navigation layout.

2

Interactive Recommendation & Visualization

Create mood-based filters. Add budget and neighborhood comparison functions. Implement charts using Plotly for visualization.

3

UI Improvement & Real Data Integration

Apply a clean and modern design theme. Add real exhibition and cultural space data. Improve responsiveness and finalize the dashboard for deployment.

✦ Academic & Creative Value

As a Dance major, this project reflects an interest in the relationship between space, atmosphere, and emotional experience. By organizing exhibition and cultural space data into an interactive recommendation system, the dashboard transforms subjective feelings into a data-driven cultural experience — providing a more personalized way to explore Seoul's art and exhibition scene.
